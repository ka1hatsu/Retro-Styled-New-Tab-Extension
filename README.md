For using this as an extension in your browser follow the steps below:

1. Download the index.html, manifest.json, app.js and put them in a single folder.
2. Then open up your extension tab in your browser (`edge://extensions/` for Edge, `chrome://extensions/` for Chrome, `brave://extensions/` for Brave).
3. Enable **Developer mode** using the toggle switch (located in the left sidebar on Edge, or in the top-right corner on Chrome/Brave).
4. Click the **Load unpacked** button that appears.
5. Select the folder containing your downloaded files (`manifest.json`, `index.html`, and `app.js`).
6. Open a new tab (`Ctrl + T`). If your browser prompts you to confirm changing the new tab page, select **Keep changes**.
